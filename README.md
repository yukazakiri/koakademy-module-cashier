# KoAkademy Cashier Module

Cashier workflows for student balance lookup and payment posting.

## Installation

```sh
composer require koakademy/cashier:^1.0
```

This package targets KoAkademy 1.20+, PHP 8.5, Laravel 13, Filament 5, and
`nwidart/laravel-modules` 13. It is licensed under AGPL-3.0-or-later.

Run the host application's migrations after installation.
